# Titanic Survival Prediction

A machine learning project that predicts which passengers survived the Titanic disaster.

## What this project does
- Loads and cleans real Titanic passenger data (891 passengers)
- Handles missing data and encodes categorical variables
- Trains a Random Forest Classifier
- Achieves 82% prediction accuracy

## Key findings
- Sex was the strongest predictor of survival (women prioritized)
- Fare and Age were also highly important features
- Model outperforms baseline guessing by over 20%

## Tools used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## How to run
Open the notebook in Google Colab and run all cells in order.
